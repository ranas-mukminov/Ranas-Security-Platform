# ScopeProof Lab — локальная лаборатория по безопасности

**Версия 0.1, демонстрационный проект.** Всё выполняется локально и на искусственных данных. Код не обращается к инфраструктуре заказчиков, не проверяет внешние адреса и не заменяет письменное разрешение на пентест.

Рабочие сценарии:

1. **AUTHZ-LAB-001:** в учебном сервисе один пользователь читает чужой объект, после включения проверки владельца доступ запрещён.
2. **RBAC-LAB-001:** два Kubernetes-манифеста в формате JSON — чрезмерно широкая роль и ограниченная роль. Проверка показывает разницу до и после исправления.
3. **Scope Guard:** проверка допустимого метода, локального адреса, исходного IP, порта и периода. Запрещает любые внешние цели. Поддерживает экстренную остановку и ограничение числа синтетических действий.
4. **Evidence Chain:** журнал событий с SHA-256-цепочкой, отдельная команда проверки целостности и отчёт Markdown.

Запуск:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests -v
scopeproof demo --out artifacts/first-demo
scopeproof verify --events artifacts/first-demo/events.jsonl
```

Это **не инструмент автоматического внешнего пентеста**, не подтверждение юридического согласия заказчика и не гарантия допуска в OpenAI Daybreak либо Anthropic Cyber Verification. Для реальных работ необходимы отдельные полномочия, условия тестирования и человеческий контроль.
